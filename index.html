🔐 Sobre los admins
Los admins se marcan con el flag isAdmin: true en su documento de la colección users. Desde este panel podés promover/degradar jugadores (con el botón ⚡).

⚠️ Primer admin: si nadie es admin todavía, entrá a Firebase Console → Firestore → users → (tu documento) y agregá manualmente el campo isAdmin (tipo boolean) con valor true. Después recargá la página.

Reglas de Firestore (modo dev)

⚠️ Las reglas actuales de tu Firestore deben permitir leer/escribir a usuarios autenticados. Copiá y pegá esto en Firebase Console → Firestore → Reglas: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function signedIn() { return request.auth != null; }
    match /users/{uid} {
      allow read: if signedIn();
      allow create: if signedIn() && request.auth.uid == uid;
      allow update: if signedIn();
      allow delete: if signedIn();
    }
    match /shopCards/{id} {
      allow read: if signedIn();
      allow write: if signedIn();
    }
    match /shopItems/{id} {
      allow read: if signedIn();
      allow write: if signedIn();
    }
  }
}
Estas reglas son permisivas para desarrollo. Para producción real necesitás validar isAdmin del lado servidor o usar Cloud Functions.
